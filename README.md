# JR Fun - Personal Portfolio Website

A modern, stylish, and highly attractive personal portfolio website designed to showcase your skills, projects, and personality.

## 🌟 Features

### Design & Aesthetics
- **Modern Gradient Design**: Beautiful gradient backgrounds and color schemes
- **Smooth Animations**: CSS animations and transitions for enhanced user experience
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Elements**: Hover effects, scroll animations, and dynamic content
- **Professional Typography**: Clean and readable fonts with proper hierarchy

### Sections Included
1. **Hero Section**: Eye-catching introduction with animated elements
2. **About Me**: Personal information with animated statistics
3. **Skills**: Showcase of technical skills with interactive cards
4. **Projects**: Portfolio of work with project details and links
5. **Contact**: Contact form and social media links

### Interactive Features
- **Smooth Scrolling Navigation**: Seamless navigation between sections
- **Mobile-Friendly Menu**: Responsive hamburger menu for mobile devices
- **Contact Form**: Functional contact form with validation
- **Scroll Animations**: Elements animate as they come into view
- **Floating Shapes**: Animated background elements for visual appeal
- **Counter Animations**: Animated statistics in the about section
- **Scroll-to-Top Button**: Easy navigation back to the top

## 🚀 Getting Started

### Option 1: Direct File Opening
1. Double-click on `index.html` to open in your default browser
2. Or run `open_website.bat` for a quick launch

### Option 2: Local Server (Recommended)
For the best experience, serve the files through a local server:

```bash
# If you have Python installed
python -m http.server 8000

# If you have Node.js installed
npx serve .

# If you have PHP installed
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## 🎨 Customization

### Personal Information
Edit the following in `index.html`:
- Replace "JR" with your name/initials
- Update the hero section text
- Modify the about section content
- Add your actual projects and skills
- Update contact information

### Colors & Styling
The main color scheme uses:
- Primary: `#6c5ce7` (Purple)
- Secondary: `#fd79a8` (Pink)
- Accent: `#fdcb6e` (Yellow)

You can easily change these colors in `styles.css` by searching for the color codes.

### Adding Your Photo
Replace the placeholder icons with your actual photos:
1. Add your photo files to the project folder
2. Update the `.image-placeholder` and `.image-frame` sections in the CSS
3. Replace the `<i class="fas fa-user-circle"></i>` with `<img>` tags
